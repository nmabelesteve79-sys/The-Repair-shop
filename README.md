The program contained in the repair shop can be said to run the management system of a repair shop, 
that has a list of items that can be fixed, the particular problems the items might posses that can be fixed and a fixed price for each repair.
This management system can only be acessed by the workers in the repair shop.
When this program is runed, you will be brought to a menu which you have a list of options to choose from.

let's say you choose the first menu which is "Add repair job" you will be given a template of info to fill in
e.g
Customer: Kate
Item: Television
Problem: No sound
Status: pending
Cost: 32250
As soon as you input the first 4 items, the cost of the repair which is determined by the "item and problem" will automatically appear. 
The data for Kate will now be stored automatically in the dictionary allocated for costumers data.

2 - View all repairs: All the data for each customer will appear.

3 - Search for a repair: Allows one to get all the information of a particular customer, just by inputting the name of the customer.

4 - Update repair status: You will be asked who's status will you like to update, you should enter the name of the person
and choose what you'll want to update their item repair status to. But what does status mean, it literary means what state is the item to be repaired currently in.
When you fill up the info of a customer initially, the status is set to pending meaning you have not yet worked on the item. 
So, when you update it to for instance "In progress" it means you have started repairing the item but have not finished the repair yet.
If updated to "completed" it means that you have now finished the repair and it's ready for pick up.

5 - Calculate total earnings: This calculates the total cost of all the items that their status has been updataed to completed, so that you can see the worth
of all your labour.

6 - Exit: This os to exit the system.

CAUTION NOTE:
--> When choosing what you want to do use numbers (1, 2, 3, 4, 5, 6)
--> When choosing what status you want to update to, you type the words out completely (pending, in progress, completed)
